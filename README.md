# QA-досье Wiregate

Разбор тестового задания [rndx2-public/wiregate-test-task](https://gitlab.com/rndx2-public/wiregate-test-task)
(коммит `8eedbff`): форма регистрации на React, NestJS и Postgres.

**Отчёт открывается по ссылке, ничего устанавливать не нужно.**
Переключение русского и английского языка и светлой и тёмной темы — на самой странице.

|---|---|

| задокументированных дефектов | 78 |

Каждый дефект атомарен и оформлен по шаблону: заголовок, описание с влиянием,
пронумерованные шаги воспроизведения, фактический результат дословным ответом
системы, ожидаемый результат, способ исправления и локализация по коду с точностью
до строки. Ни один дефект не взят из чтения кода: все воспроизведены на поднятом
локально стеке Docker.

## Регрессионный прогон

Требует поднятого стека тестового задания: скрипт стучится в `localhost:8000`
и читает базу через `docker exec`. Адрес и имена контейнеров переопределяются
переменными `API`, `DB_CONTAINER`, `BE_CONTAINER`.

    bash api-checks.sh

Проверки написаны на правильное поведение, а не на текущее, поэтому строка `FAIL`
означает подтверждённый дефект, а не поломку прогона. На момент составления:
`PASS 5`, `FAIL 25`. После исправления дефекта соответствующая строка станет зелёной.

Эквивалентное разбиение, анализ граничных значений, таблица решений,
переходы состояний, попарное тестирование, предугадывание ошибок,
тестирование безопасности и совместимости, исследовательские сессии.
Привязка техник к конкретным кейсам и находкам — в разделе отчёта
«Техники тест-дизайна».
